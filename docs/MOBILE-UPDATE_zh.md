# 手机图解与开场视角更新 1.3.2 · 2026-11-21

## 呈现与操作

- 手机/平板采用单行导航、两行工具栏；横屏压成一行工具栏。英文控件保留可访问名称，手机 Hint 和 Journey map 通过 Help 打开。
- 操作练习以四幅本地 SVG 图解展示旋转、两点连接、撤销重做、测试暂停。每一步只显示一幅小图和一句动作，使用真实控件完成。
- 手机教学提示与测试读数位于独立布局栏，不再浮在桥梁上；相机工具保持在场景上缘。
- 任务先展示货车、实际支座位置、跨度及载荷/跨度/预算。示意图不预先绘制解题桁架。完整故事、目标、规则、材料、Bloom 标签可展开查看。
- 失败与成功先保留结果、关键测量和下一步动作；证据、解释、角色、现实连接及奖励按需展开。三阶段释放条件与每次实验 CER 保存规则延续 1.3.1。
- 竖屏建造视角稍微拉近。开场以约 9°、3.2 秒的一次往返缓慢转动暗示空间深度，同时用双指图示提示旋转。触碰场景/控件、键盘输入或滚轮即停止；返回菜单不重复；减少动态效果设置禁用该转动。
- 对话框打开时停止相机输入及自动视角运动，仿真沿用原暂停规则。图示、英文短句和完整可展开说明均为本地资源，可离线使用。
