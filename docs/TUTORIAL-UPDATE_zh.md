# Riverbend 1.4.4：聚焦教学、旋转视角与音效

日期：2026-11-25

## 玩家流程

新旅程在故事后直接进入第一关“搭建你的第一座桥”。教程与本关共用设计与测试，亲手搭好的桥通过后可直接交付、继续柳溪，无需练习后重搭。

1. 指针指向木材按钮，点击后进入搭建教学。
2. 半透明鼠标／手指按住①，沿路径拖动到②，再松开；鼠标左键变色，端点出现点击涟漪，拖动路径逐步亮起。两侧半透明桥杆显示目标位置。
3. 玩家搭出第一根支撑后，提示撤销、重做。
4. 第二根支撑演示点①、再点②，说明拖动与依次点击两端均可搭建。
5. 指针指向测试按钮，并提示暂停观察受力；测试通过后按原有交付和小测验继续下一关。

## 输入与存档

- 演示不生成真实构件，不消耗预算，也不自动产生实验记录；只有玩家实际操作与测试写入设计、实验和笔记。
- 半透明指针不拦截输入，真实按下时自动隐藏；真实点击有涟漪反馈，连接成功有绿色反馈。
- 教程可随时重播、跳过。刷新后保留真实设计并恢复到合适步骤；清空、撤销、失败重试都可继续。
- 旧存档已看过操作教学或已完成第一关时正常续玩；菜单中的“操作练习”仍单独运行，不计主线测试与笔记。
- 桌面显示鼠标与左键按下提示；触控设备显示手指。中英文同步。
- 320px、390px和横屏采用场景外的短提示栏；帮助等弹窗隐藏演示并阻止相机输入。
- 减少动态效果时，显示静态手势与①②路径，不播放自动指针拖动、按键动画和开场相机转动。

## 技术与验证

本轮保留关卡、预算、材料、物理、版本1存档和原三份核心测试。新增 `site/js/ui/tutorial.js`，独立管理临时 Three.js 半透明构件及 SVG 指针。临时构件不进入 BridgeModel/BridgePhysics，退出与显卡恢复均清理或重建。

`node scripts/verify-tutorial.cjs` 验证全新存档、真实鼠标拖动、点击、撤销重做、实时通车、实际触控拖动、双语、小屏、刷新、跳过、失败后编辑、旧存档、减少动态、资源重复构建与显卡恢复。旧存档兼容检查明确使用种子存档；主教学流程不加载参考桥、不加速求解器。

验收记录见 `output/tutorial-upgrade/`，最终包记录以 `completion.json` 为准。自动 Chrome 验证不等同实体手机/Safari验证或真人学习成效测试。


## 1.4.4 补充（2026-11-25）

- 第一关先点击旋转按钮，观看半透明指针左右拖动并带动真实相机；玩家实际拖动后，提示点击正面按钮回到搭建视角。旋转模式不会添加构件。
- 灰色半透明 SVG 遮罩随步骤开窗，突出当前控件、教学卡与桥梁目标。帮助、退出、语言和音效开关始终清晰可达；遮罩不拦截鼠标或触控。
- 点击、连接、撤销、重做、清除、测试启动、暂停、断裂与测试结果使用本地 Web Audio 合成短音。首次真实操作后才能启用；静音立即停止当前音效，并以独立偏好保存。后台或失焦时停止声音。
- 手机单指旋转、实际搭建、横屏和320px屏幕；键盘可用“下一步：正面”继续；减少动态时不播放相机／指针动画。
- 旋转完成只存布尔教学标记，存档结构、真实桥杆、预算、两章连续流程和物理不变。已有教程进度继续保留。

新增验收：`node scripts/verify-focus-audio.cjs`，含真实鼠标旋转、原生触控、聚焦开窗与点击命中、帮助与跳过、减少动态、音频波形非零采样、静音即时停止和刷新记忆。完整包证据见 `output/focus-audio-upgrade/completion.json`。浏览器音频采样不代表实体扬声器听感或真人学习成效。
