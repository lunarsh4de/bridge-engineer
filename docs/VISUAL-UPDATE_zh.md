## 打开与打包

直接双击项目根 `index.html`。发布包解压后使用相同入口。

`python scripts/sync-pages.py --check`

`node --test tests/*.test.cjs`

`python scripts/package-release.py`

发布包采用明确的允许目录，只包括运行文件、现有测试、脚本和项目文档；不包括 output、凭据、环境变量或机器缓存。

## 回滚

回滚包：`output/rollback/riverbend-original-20261121.zip`。它是在修改前创建的完整 47 文件快照，包含 Phaser 离线依赖，以及每个原始文件的 SHA-256 清单。

简单方式：关闭游戏，解压回滚 ZIP，把当前 `riverbend-v1` 改名保留，再使用解压出的 `riverbend-v1`。原项目所有文件会恢复到本次修改前。

脚本方式：在 PowerShell 中运行同目录的 `Restore-Original.ps1`。脚本校验 ZIP 哈希和目标目录名，把新版移到旁边的备份目录，再恢复原版；没有递归删除操作。此脚本仅提供给用户按需运行，本次没有执行回滚。

浏览器存档不在项目文件中。建议先用 Help → Settings 导出存档，换目录后按需导入。回滚脚本不修改浏览器数据。
