# 离线运行说明与教师试玩提示

解压整个 ZIP，双击 index.html 即可运行。请保留 js、vendor 等文件夹，不能只复制 HTML。无需安装、联网、登录或 API Key。游戏界面为英文。

建议首先使用桌面版 Chrome 或 Edge。当前实际验证为 Chromium；其他浏览器与真实触屏设备尚未实测。手机尺寸布局已经模拟检查，复杂搭建建议使用电脑。

进入即玩：选择 Road，从橙色锚点拖到另一侧；选择 Timber，拖出三角支撑；点击 Gravity lab 观察自重，或 Test crossing 测试车辆载荷。端点相遇连接，交叉处不自动连接。Move 调整节点，Erase 删除，Undo/Redo 撤销与恢复。可选择 Try a starter design 探索示例。右上角 About 说明 STEM 主题、故事、学习目标与模型边界。

三个关卡依次引入有限木材、更多木材与更大跨度、钢材和仅承拉的缆索。教师可观察学生是否形成三角支撑、建立连续受力路径，并依据下挠或断裂证据调整设计。过关条件为车辆通过、构件无断裂、最大桥面下落低于 12 cm；不以操作速度评分。

教学对应：

| 学习目标                 | 策略                 | 玩家行为                               | 反馈                     | 可观察证据                 |
| ------------------------ | -------------------- | -------------------------------------- | ------------------------ | -------------------------- |
| 在材料限制内搭建承重结构 | 分块、示范与实践     | 三关递进，选择性使用示例，搭建三角结构 | 自重、变形与通车结果     | 同一载荷下可重复通车的设计 |
| 用变形或断裂证据改进结构 | 探究、问题解决、反馈 | 先预测，每次改变一个变量，再测试       | 下挠、失败构件、拉压颜色 | 修改前后的设计与结果比较   |
| 将结构知识用于新情境     | 故事情境与迁移       | 为社区不同需求解决更大跨度与载荷       | 材料预算和通车条件       | 在新关卡应用支撑与材料选择 |

这些是本 demo 的教学设计映射，不代表已逐项核对全部课程附件，也不代表自动测得概念掌握。玩家可在 About 与 field note 阅读原理、Forth Bridge 案例及来源。

声音按钮可静音，设置和设计在浏览器允许时本地保存；更换电脑不会自动转移进度。受限浏览器仍可游玩，但关闭后可能丢失进度。系统减少动态效果设置会关闭装饰动画、震动与庆祝粒子。

本版本使用 Phaser 3.90.0，MIT 许可见 vendor/PHASER-LICENSE.md。结构求解器为独立的简化轴向模型。车辆在受支撑时采用指定移动载荷，非完整轮胎接触动力学，不能用于真实桥梁安全评估。实际测试范围见 docs/TEST_REPORT.md，参考与架构见 docs/research/bridge-workshop-architecture.md。
