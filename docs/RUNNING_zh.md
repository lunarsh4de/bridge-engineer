# 离线运行与教师试玩说明

版本：0.6，2026-11-06。游戏内文字为英文，教师说明为中文。

## 启动

解压完整游戏包，双击根目录 index.html；源码目录则打开 site/index.html。必须保留 js、vendor 等相对目录。无需联网、安装、账号、CDN 或 API Key。

首页是全屏游戏菜单：Start、Select level、Free build、Replay story 和右上角 About。首次按 Start 后显示四格序章：断桥和幼苗、两名学徒与导师的三角形桌面模型、从安全河岸搭半桥、橙色小车送幼苗过桥；接着进入独立 Training Yard，实际选择材料、连接道路、按高亮补完框架、运行测试并返回编辑。序章和训练均可跳过；以后可重播，训练不覆盖主线设计。已完成或跳过训练后 Start 恢复上次主线；刷新仍回菜单。Free Build 可从主菜单直接进入，也保留选关界面的 Riverbend Lab 卡片。

Select level 依次解锁八关；Explore all levels 供教师独立查看；Free Build 是单独的 Riverbend Lab，不计入主线完成度。沙盒可选择 600、1,800、3,200、4,800 kg 载荷，比较记录按载荷隔离。

## 搭建与实验

- Road 从一个端点拖到另一个端点；长路面自动分段并形成一次可撤销操作。也可点击两端。
- Timber / Steel / Cable 自由放置。端点吸附连接，中段相交不连接。移动端无需 hover 才能搭建。
- Move 移动自由节点；Erase 回收材料；Undo/Redo 完整恢复操作。Restart 明文按钮打开确认框，可保留设计或清空，清空本身仍可 Undo。未完成手势可 Esc / Cancel 取消；画布外释放也取消。
- Self-weight 观察自重；Test crossing 先静置，再施加移动配送载荷。Forces 显示拉/压颜色，指向或点选构件可读英文受力信息。
- 测试成功条件：配送完成、无构件断裂、最大桥面下落小于 12 cm。这是游戏规则，不是真实桥梁安全标准。
- 失败后 Edit design 恢复原设计，不用重新从零搭建。打开帮助会暂停测试，关闭后需主动 Resume。

## 主动教学与 About

Task 显示情境、材料/跨度/载荷和成功条件。Help 分为 Controls、Structures、Real bridges、Settings。结构示例只在主动点击后加载，替换设计前说明且可以 Undo。现实案例为 Forth Bridge 和 Queensferry Crossing，必要事实摘要随包提供，延伸外链离线时不可访问但不影响游戏。

About 位于右上角，概述 STEM 工程分支、11–14 岁且建议成人引导的目标学习者、45–75 分钟目标、三项可测学习目标、ABCD/Bloom、5E、探究／问题解决、证据与边界。课程 mind map 与 game rubric 已实际查看并据此映射；这是设计对齐说明，不是成绩保证或学习成效研究。

## Notebook 与学习评价

Notebook 提供可选预测，自动保存最近八个不同设计的完整测试记录，包括设计快照、条件、下挠、断裂、材料成本；可填写反思并恢复旧设计（可撤销）。相同测试类型、跨度和载荷下的不同设计才作比较。相同设计重复测试不会产生额外记录或奖励。

Material saver 是相同条件下更低成本的成功方案记录。游戏成本按米计：Road 1、Timber 1、Steel 3、Cable 1.2，不是现实价格。没有速度排名、尝试惩罚或强迫使用帮助。

建议教师观察三类证据：

1. 学生能否在相同载荷下改变结构连接，引用下挠/首断结果解释稳定性变化。
2. 能否判断构件拉压角色，解释缆索不能受压，以及换钢的自重代价。
3. 能否用“问题—预测—修改—结果”组织一次迭代，并在另一关重新判断。

过关、保存反思或出现奖励都不等于概念掌握。目标年龄、先备知识与正式量规确认后再设评价阈值。

## 保存与迁移

旧三关／四关有效存档可迁移到八关。每关设计、完成记录、Free Build 设计和实验记录分别保存；沙盒不同载荷不会互相比较。存储被禁用时会话仍可玩，尝试保存后会出现 Not saved on this device；关闭／刷新可能丢失本会话内容。

Help → Settings → Export progress 下载 JSON；另一台电脑使用 Import progress。导入经格式与设计校验，确认后替换本机进度。可先导出备份。声音开关与原生全屏也放在 Settings。

## 实测范围与模型

本机 Chromium 的实际自动化范围详见 TEST_REPORT.md；v0.5 数值审计见 `docs/LEVEL_AUDIT_v05.json`。模拟手机尺寸不等于实体触屏兼容认证；Safari/Firefox、课程考核设备、正式无障碍评估和学生学习成效仍待验证。

Phaser 3.90.0 负责场景与交互，独立求解器处理轴向构件和固定步长重力实验。车辆是规定移动载荷，不是完整轮胎接触模型；理想铰接模型省略真实弯曲、连接破坏、疲劳和风。不能用于真实桥梁安全评估。

## v0.6 完整游玩流程

每个新关首次进入会显示短任务简报；进入施工后左上目标常驻，Hint 分为观察提示和原理提示，均可选。失败卡以 Edit design 为主要行动，解释测得的下落、首断或连接问题；成功卡以 Next crossing 为主要行动，配送后果和社区路线保留。失败不会清除历史通关。

选关顶部的八站路线记录已连接社区。最后一关完成后进入独立的 Field report：显示个人保留的通过设计、最大下落、断裂数和材料成本，并提供 Improve、Free build 和 Menu。部分完成时也可从主菜单回看报告，未完成社区明确显示等待配送，不能绕过主线锁定。旧档缺少测量时会说明缺少保留记录，不伪造设计或得分。

Notebook 优先呈现两案比较与最近记录，预测和较深入资料可展开。反思可用“我的修改是什么／哪项测量支持它／为什么”作简短口头或文字说明，但不强制作答，不自动将其评为掌握。材料节约章基于相同条件的两条成功方案，不按速度或失败次数奖惩。

完整主线与教师快速抽查不同：完整版本含八关、训练、沙盒、结局和保存；教师可用 Explore all 直接抽查第1/4/5/7关观察三角形、缆索、桥墩和重载，不因此伪造完成。具体引导和四类学习映射见 RIVERBEND_v06_LEARNING_DESIGN_zh.md。

本轮实际支持范围、独立验收、未测浏览器和学习效果边界以 TEST_REPORT.md 为准。建议桌面 Chromium，平板和窄屏应按实际验证范围使用；不能把CSS缩放或触控仿真等同于所有真机兼容。
