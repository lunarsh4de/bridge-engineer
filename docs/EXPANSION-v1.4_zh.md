# Riverbend 1.4.0：第二章、实桥图解与双语

日期：2026-11-21。编辑源码在 `site/`；根目录由 `scripts/sync-pages.py` 同步。浏览器直接打开 `index.html` 可离线游玩。

## 章节与关卡递进

第一章保留桌面模型、柳溪、蕨谷/石滩分支、回声峡谷与河湾终章。每条路线五次过桥，终章三种支承合计八个基础场景。1.4.2 起，第一章交付完成后直接进入第二章；已有第二章进度则继续原进度。主菜单仍允许直接访问第二章，不要求先通关；两章进度、设计、测量记录与文字笔记分开保存。语言设置跨章节保留。

| 第二章关卡 | 条件 | 玩家行动与证据 |
|---|---|---|
| 双车同渡 | 8米；1.6吨×2；车距3米 | 观察两车同时上桥，比较同条件下的峰值与下挠；必须两车均送达 |
| 给高船留出空间 | 10米；1.8吨；船需3.6米包络 | 选桥面高度、避让船道；低桥面或桥下斜撑会阻挡，结果指出构件 |
| 一座岛，两段桥 | 14米总长；中间2米岛；两个6米水上跨度；2.6吨 | 两段独立支撑，测试完整渡河；只支持一侧会失败 |
| 通航与车队 | 12米；2.1吨＋1.5吨；车距3.4米；一条船道 | 同时满足共同活载、加载后净空与预算 |
| 河港综合工程 | 18米总长；中间2米岛；两个8米跨度；2.4吨＋1.8吨；两条船道 | 组合设计，全部车辆、全部航道、结构与费用必须在同次测试满足 |

通航关水面为-3米，桥面可抬高0/1/2米。默认1米，蓝色盒框表示船舶所需空间。高度是试验条件，应用新高度明确清空支撑、重铺道路；历史记录保留。每关提供两个通过数值审计的示例（桁架/斜拉），可在自行尝试后通过提示载入。示例不是唯一或最优答案。

## 教学流程

沿用“图示任务→预测→实际搭建→测试观察→首次失败解释→单项修改与同条件复测→成功联系现实→简短概念检查→交付”的过程。笔记可选，预测在开测前冻结，之后记录观点、证据、推理。重试、星级、答题或文字长度不自动表示掌握。

第二章笔记将车辆质量和间距、桥面高度、水位、船道位置和净空、岛段、支座、材料和预算一并写入条件；不同条件不能作为控制变量比较。导出/导入保留扩展条件，并检查无效车辆与航道数据。

## 实桥案例

第一章依次联系博尔曼铁路桁架桥、科尼什—温莎廊桥、昆斯费里大桥、福斯铁路桥、米约高架桥和里翁—安蒂里翁大桥。第二章联系金门大桥、悉尼海港大桥、旧金山—奥克兰海湾大桥、厄勒海峡大桥及里翁—安蒂里翁大桥。

每关任务页均有可展开照片卡：照片、所在地、相关原理、游戏与现实的差异、照片作者和许可、原始图片页面、桥梁资料。照片均为真实建筑的开放授权图像，本地存储，运行时不联网。海湾大桥采用1936年历史航拍，明确说明东段已于2013年替换。详细来源见 `BRIDGE-CASES.md` 与 `../assets/bridges/SOURCES.json`。

## 中英文与手机

菜单和工坊均可切换中文/English。菜单、故事选择、关卡目标、提示、检查题、操作教学、错误、受力解释、笔记和报告采用本地翻译。切换不重建3D场景，不改变设计、模拟或用户笔记。默认跟随浏览器语言，手动选择保存在本地。

任务图示优先、长文折叠；照片卡收起时仅显示小图和桥名。320像素、390像素及横屏检查包括构件锚点可见、按钮无重叠、对话框不横向溢出。第一章原有轻微开场旋转、触摸即停、减少动态效果设置继续生效。

## 模型边界

3D双侧桁架是同一二维结构的镜像。结构仍为固定步长XPBD理想铰接轴向杆件，车辆是规定位置的移动车轴荷载，不是轮胎接触、三维扭转或真实交通仿真。通航为二维构件与船舶包络的扫掠检查，计入道路/构件厚度及当前下挠；不模拟水位变化、潮汐、船舶动力或真实规范。中央岛把道路拆成两个承载跨度，不是可开合或升降桥。游戏数值不能用于真实桥梁安全判断。
