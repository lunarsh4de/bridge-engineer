# STEM 教学映射（1.3.2）

| 教学目标 | 游戏行为 | 可观察证据 |
|---|---|---|
| 识别支座与荷载路径 | 追踪构件到固定端，使用 Trace support connection | 能指出共享端点和固定支座；知道线相交不自动连接 |
| 区分拉力与压力 | 测试后观察蓝/红端标和构件颜色 | 能说出构件被拉或被压，并联系缆索松弛或压杆屈曲 |
| 解释跨度与屈曲 | Willow 中把长压杆拆成短三角网格 | 同条件复测时引用最大下落、首断或峰值利用率 |
| 进行受控比较 | Notebook 只允许相同条件比较 | 明确载荷、支座、预算、材料和测试时长没有变化 |
| 依据证据迭代 | Mill 中只替换首断构件的材料并复测 | 设计副本、单变量改动、复测结果和成本可追溯 |
| 认识模型边界 | Field report/Notebook 写 CER | 能指出二维、铰接、轴向杆件和规定移动荷载等限制 |

练习阶段的行为用于熟悉控件，不写入主线的分数、测试数或 Notebook；正式关卡才产生可回顾的工程证据。

三阶段任务按 Engage/Explore → 首次失败后的 Explain → 成功后的现实连接安排自动提示。图示先呈现任务条件，完整解释和蓝色Bloom标签可按需展开，标签表示设计意图。CER按关卡与测试编号分开保存，预先预测后再记录解释，供教师对比学生的预期和证据。具体映射与验证见 `TEACHING-UPDATE_zh.md`。
