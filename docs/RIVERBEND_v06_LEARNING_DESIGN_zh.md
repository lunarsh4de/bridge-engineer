# Riverbend v0.6 教学与故事内容设计

本文件记录 v0.6 八关内容数据的设计意图，不是学习成效证明。建议对象仍为 11–14 岁、无桥梁经验且可由成人引导的学习者；45–75 分钟仍是待课堂观察验证的设计假设。

## 内容结构

每关统一提供配送对象、首次目标、决策问题、新约束、两级可选提示、典型误解、成功与失败后果、受力解释、一个短 CER 邀请和 Notebook 指南。第一级提示只邀请观察连接、运动、受力或失效；第二级说明可迁移的结构原理，不规定必须复制的桥形。预测、CER 和反思均为可选内容，不作为继续游戏的门槛，也不由系统自动判定掌握。

故事从 Willow Creek 的幼苗配送开始，依次恢复农场、工坊、磨坊、诊所、救援通信与铸造厂，最终由救援车队完成八个社区连接。失败只表示配送延误并给出下一次可观察行动，不扣除尝试机会。

## 可观察目标（ABCD）

以下是实现意图，是否达成须由实际试玩记录或教师判断，不能由通关自动推出。

1. **比较并解释设计证据**：给定同一关、同一载荷与模式下的两次不同设计测试（Condition），11–14 岁玩家（Audience）能比较最大下落、首个断裂或过载、材料用量中的至少两项，并指出一处改变如何影响到固定支座的连续载荷路径（Behavior）；解释引用至少一项 Notebook 测量或失效记录（Degree）。
2. **按受力角色选择材料**：给定 Timber、Steel、Cable 和 Forces 显示（Condition），玩家（Audience）能为一个轴向构件角色选择材料并说明理由（Behavior）；理由至少使用“受拉/受压/松弛、刚度/强度、自重”中的两项，并能用一次测试结果核对预测（Degree）。
3. **依据失败修订**：给定一次未通过或低效率测试（Condition），玩家（Audience）能定位一条可见证据，写下或口述一个预测，修改一个结构特征并在相同条件下复测（Behavior）；留下两个可比较设计及一句简短主张—证据—推理（CER）即可作为教师观察材料（Degree）。CER、预测与反思保持可选，不影响解锁与继续游戏。

## 知识类型、动作与证据

| 知识类型 | 游戏中的具体动作 | 可供教师查看的证据 |
| --- | --- | --- |
| Factual 事实 | 识别 Road、Timber、Steel、Cable、固定支座及 tension、compression、slack、overload 标签 | 玩家能在 Forces 显示中指出一个状态；测试记录保留首断与载荷条件 |
| Conceptual 概念 | 从受载道路节点沿共享节点追踪到岸或桥墩；判断缆索是否受拉；比较有无真实桥墩连接 | 口述或短 CER 引用一条连续/中断路径、slack 状态、最大下落或失效位置 |
| Procedural 程序 | 选材、连接端点、Test、暂停观察、Edit design、撤销/重做、在相同条件复测 | Notebook 保存不可变设计快照、条件、下落、断裂与材料成本；操作过程显示是否能完成测试—修改循环 |
| Problem-solving 问题解决 | 面对新跨度、材料、桥墩或重载，预测限制，选择一次有依据的修改并检查副作用 | 两条同条件不同设计的对照，以及玩家为何改变连接、几何或材料角色的简短说明 |

这些证据支持形成性观察，不构成自动评分题库。教师可接受口述、指认画面或一句短记录，不强制作文，也不把专业术语数量当作理解程度。

## 5E 与 MDA 落点

| 框架 | Riverbend 中的实现 | 可观察但不自动判定的信号 |
| --- | --- | --- |
| Engage | 幼苗起运、社区断联、每关明确配送后果；测试前可选预测 | 玩家提出首个风险位置或预期受力角色 |
| Explore | 从零搭建、无限重试、参考桥延后解锁、无唯一形状 | 首次自主测试、失败后仍能返回并尝试另一方案 |
| Explain | Forces、失败原因、两级提示、受力说明 | 玩家能把一个标签或测量与结构中的具体位置相连 |
| Elaborate | 8 m/10 m/12 m、混合材料、受拉缆索、固定桥墩、无桥墩与重载迁移 | 后续关卡的理由或设计不只是原样复制前关 |
| Evaluate | Notebook 只在相同条件下比较不同设计；可选短 CER | 玩家用至少一项记录证据支持一个修改主张 |

MDA 中，**Mechanics** 是放置/移动/删除构件、库存、固定支座、移动载荷、轴向受力、失效和记录；它们形成“预测—搭建—测试—观察—修改”的 **Dynamics**，以及配送紧迫感、发现结构规律、修复社区和表达个人方案的目标 **Aesthetics/experience**。这是设计映射，不是情感或学习效果的实测结论。

## Goal、Rule、Reward、Challenge 对应

| 要素 | 实际设计 |
| --- | --- |
| Goal | 让连续道路在规定移动载荷下无断裂且最大下落低于游戏的 12 cm 限值，并完成当关配送 |
| Rule | 库存按长度限制；构件只在共享节点连接；固定岸与第 5/8 关桥墩提供支承；Cable 只受拉；失败不消耗库存或尝试次数 |
| Reward | 解锁下一社区、路线站点与配送后果；同条件下两个成功设计才可能得到材料节约反馈，不奖励速度或少失败 |
| Challenge | 跨度、载荷、材料角色与支座条件逐关变化；第 4/6 关辨别缆索受拉，第 5/8 关真实连接桥墩，第 7 关承受重载 |

奖励表示游戏进度，不代表概念掌握、成绩或现实工程能力。

## 分块、故事与两级提示

信息按“当关配送与目标 → 自主搭建和测试 → 一级观察提示 → 二级原理提示 → 可选受力解释/Notebook”逐层呈现。玩家不必先读长篇课程说明。八关的一级提示分别观察：框架变形、共享节点路径、高需求材料角色、缆索松弛、桥墩真实连接、无桥墩路径闭合、重载首次警告、两个半跨及缆索状态。它们不指定固定参考形状。

二级提示再给可迁移原理：对角连接能限制四边形改变角度、载荷路径必须连续、材料按受力角色选择、缆索只能受拉、固定桥墩须共享节点、无桥墩系统须闭合到两岸、重载提高力与变形、终局需分别检查半跨再核对整体。参考桥仅在玩家先测试自己的设计后可选加载，是可撤销样例，不是标准答案。

故事后果与工程决策对应：幼苗、收成、机械、水轮部件、医疗物资、救援电台、发电机与最终救援车队各自到达或延误。故事提供行动理由和可见社区变化，但不替代受力证据。

## 教师引导与两种试玩路径

### 课前/开局 5–10 分钟

1. 指出固定岸、道路与材料库存，请学生预测“车到哪里时最可能先出现明显变形”。
2. 示范一次 Test、暂停、Forces 与 Edit design，不示范完整桥形。
3. 约定证据语言：先说看到的下落、断裂、overload 或 slack，再说为什么修改。
4. 提醒 Notebook 只比较相同关卡、载荷、模式与支座条件下的不同设计；现实桥梁不能按本游戏判据认证。

### 最短形成性观察路径

当课堂时间不足时，可由教师 Explore 解锁后选择第 1、4、5、7 关，各完成一次预测—测试—修改—复测：第 1 关观察稳定与连接，第 4 关检查缆索受拉/松弛，第 5 关比较是否真实连接桥墩，第 7 关判断重载限制。最后从其中一关选择两条同条件记录，口述或写一句 CER。此路径用于快速抽样四类判断，不算完成剧情、路线或八关递进，也不能据此声称已覆盖全部学习体验。

### 完整八关路径

按 1–8 顺序游玩才能经历故事重连、材料与支座递进、无桥墩迁移和最终综合任务。建议在第 2、3、6、8 关各追问“这一关为什么不能只原样复制上一关？”完整路径预计 45–75 分钟，但该时长尚未经课堂实测，实际会随阅读、搭建与讨论速度变化。

## API 与兼容性

`levels.js` 保留已有 `story`、`constraint`、`concept`、`lesson`、`hint` 和 `explanation` 字段，并为八关增加 `learning`。`content.js` 提供 `getLearning(level)`、`hint(level,index)`、`failure(level)`、`success(level)` 与 `notebookGuide(level)`。旧关卡或 Free Build 没有 `learning` 时由旧字段生成完整回退对象，因此现有调用与沙盒不会得到空值。

## 模型与证据边界

受力说明只描述游戏的固定步长、铰接轴向构件模型。车辆是规定移动载荷，不是完整轮胎接触动力学；模型省略梁弯曲、真实屈曲形态、节点破坏、疲劳与风。12 cm 是游戏规则，不是工程规范。固定中心桥墩只在第 5、8 关存在；第 6 关明确没有桥墩。参考方案不是唯一答案、最优方案或现实安全认证。

内容沿用 v0.5 已核实的课程资料与公开来源许可边界，没有新增第三方图片、题库或网页事实。完成关卡只能说明配送在模型判据下通过，不能据此宣称学习有效、容易上手或获得高分。

## 现实案例与来源边界

Help 中的现实案例沿用已核实资料：Forth Bridge 于 1890 年开放，是钢制悬臂铁路桥；Queensferry Crossing 于 2017 年 8 月 30 日开放，是三塔斜拉桥。事实来源均为 Transport Scotland / Forth Bridges：

- [Forth Bridge](https://www.theforthbridges.org/about-the-forth-bridges/forth-bridge/)
- [Queensferry Crossing](https://www.theforthbridges.org/about-the-forth-bridges/queensferry-crossing/)

游戏只迁移“连续载荷路径”和“缆索承担拉力”等有限原则，不声称短跨铰接桁架复现上述桥梁。未嵌入第三方照片或工程图。MDA、CMU Learning Principles 与 NGSS MS-ETS1-3 的既有来源及许可/用途记录见 `docs/research/riverbend-v04-decisions.md`；它们用于设计参考或外部比较，不是课程认证或成效保证。
