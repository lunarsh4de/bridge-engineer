# Riverbend 1.4.0 发布说明

日期：2026-11-21

## 主要更新

- 新增第二章五关：双车同渡、给高船留出空间、一座岛两段桥、通航与车队、河港综合工程。
- 车辆从单车扩展为独立车队；所有车辆都要完成，结果显示每辆车状态。
- 通航关加入船舶动画、蓝色净空包络、最低净空、阻挡构件和桥面高度选择（0/1/2米）。低桥面和桥下支撑可明确挡船。
- 中间岛把桥面拆成两个独立承载跨度；缺任一跨支撑会失败。
- 第二章独立保存进度、设计、工程笔记和条件；高度/车队/水位/航道不匹配时不能进行控制变量比较。
- 第一章六个关卡和第二章五个关卡都提供本地真实桥梁照片、作者、开放许可、图片页面、桥梁资料和“现实与游戏差异”。
- 全游戏增加中文 / English 切换，保存语言偏好；切换不重建3D场景、不改变设计和用户笔记。
- 手机任务页以图示、关键数字和折叠文字为主；照片卡默认收起，小屏和横屏均通过布局检查。

## 验证

- 68 个 Node 单元与数值检查通过。
- 基础 3D 回归：15/15；基础教学：12/12；基础手机：9/9。
- 进阶全流程：7/7，覆盖双车实时暂停、低桥挡船、抬高桥面、照片卡、双语、五关推进、双章存档和 320/390/横屏布局。
- Pages 镜像已同步并通过 `python scripts/sync-pages.py --check`。
- 独立解压包 CRC 与 130 文件 SHA-256 清单通过。

## 模型边界

XPBD 仍是固定步长、理想铰接、二维轴向杆件模型；车辆是规定移动轴载，通航是二维构件扫掠包络。桥面高度、水位、净空和预算是游戏条件，不是现实桥梁规范或安全结论。实桥照片只用于观察结构思路，关卡并非按实桥尺寸复制。

包：`output/releases/riverbend-3d-v1.4.0-20261121.zip`。最终哈希由同目录 `.zip.sha256` 和开发输出的完成记录提供，避免在包内嵌入其自身哈希。
