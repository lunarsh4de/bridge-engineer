## 证据口径与执行约束

- **工程通过（E）**：代码路径、状态不变量、自动测试、屏幕尺寸、保存迁移、离线资源等可确定复现的结果。
- **游戏性观察（G）**：玩家是否看懂主行动、失败后是否知道怎么改、关卡是否需要新判断、节奏是否顺畅。必须来自作者完整试玩或未经指导的新手观察；按钮存在、自动测试通过和截图好看都不能替代。
- **教育证据（L）**：玩家能否依据同条件记录指出构件/测量并解释修改。通关、填写过反思、使用参考桥不等于掌握；未做学习者观察时只能写“尚未验证”。
- 每项验收结论分别记 `E: Pass/Fail/Not tested`、`G: Observed risk/Pass/Not observed`、`L: Evidence present/Absent/Not observed`。不得把一个维度的 Pass 传播到另两个维度。
- **本轮任务完成状态（适用于 RB-001 至 RB-017）**：未来改动的验收均尚未执行，记 `E: Not tested`、`G: Not observed`、`L: Not observed`；这不抹去现状证据。主代理已实际查看菜单→选关→第1关施工→Task，在约319px内嵌窗口观察到顶栏About挤出，此现状界面缺陷记 `E: Fail（该尺寸/路径）`。没有完整试玩或学习者研究；历史自动测试须标日期，不当成本轮新测。后续逐项注明证据来源、版本、范围和时间。
- 保留当前大量未提交改动；禁止回滚、批量格式化或顺手改无关模块。关键状态、数据和行为回归先有或补上有意义的检查，再小步改动；低风险样式/文案用实际渲染与交互检查，不要求为每项变化先写镜像测试。只有耦合实际阻碍验收时才拆 `app.js`，不重写引擎或物理。

### RB-013 音画、动效与反馈一致性打磨

- **增加**：只强化与操作、失效、配送和路线完成有关的提示；力量除颜色外有形状/标签/图例；动效遵循 reduced motion；声音在首次用户手势后可恢复。
- **删除/重构**：移除无信息、遮挡测量或拖慢连续重试的装饰动效；不新增大批氛围素材取代机制反馈。
- **代码边界**：`engine.js`、`art.js`、styles/content；不改物理结果。
- **E 验收**：Canvas fallback、reduced motion、静音、后台恢复、离线资产、缺图处理通过；动画不改变按钮几何或造成状态延迟。
- **G 观察**：作者试玩判断反馈是否及时且不过度；必须描述具体场景，不写泛泛“更有打击感”。

### RB-015 作者完整试玩与未经指导观察

- **优先级**：P1，完整体验 P2 不能仅靠降级放行。
- **前置条件**：RB-014 关键路径工程通过；准备干净档、旧档和观察表。
- **增加**：作者从冷启动实际完整玩八关且至少一关不用参考桥；记录首次测试、失败后下一步、跨关决策、路线注意、结局理解、总时长和退出点。在条件允许时另安排未经指导新手观察；可先做成人可用性观察并明确局限。真人招募/教育效果研究不是本地离线软件发布门的无限期前置；未安排则G/L保留Not observed和后续验证建议，不能宣称易用或学习有效。作者/代理完整实际操作仍是工程交付要求。

## 建议执行顺序与变更边界

G0先有八关轻量schema/草案、现有审计可读、最小只读进度表达，不是提前完成八关成品。依赖顺序：`基线/状态草表/视觉标准 → RB-001 → 002/003 → 004 → 005/006 → 007 → 008/009/010 → 011/012 → 013收尾 → 015完整操作 → 016 → 017`。RB-014不是最后才开始：每批改动后执行适当回归，G3再全量执行。字段结构先定，第1/4关内容、提示、Notebook最小入口和路线最小反馈随切片生产；RB-008/009/011再扩展全量，因此无反向依赖。切片前画状态草表，RB-004负责落地，不要求先实施完再设计状态。共享UI不得各写一套。这里的任务分组不要求额外子代理；G1只是内部质量门，必须继续G2–G4。

默认不触碰：求解器物理范围、八关数量、账户/联网/排行/多人、关卡编辑器、随机无限关、真实工程安全认证、刚体车辆重写。任何数值变更都要有具体差异证据并重跑受影响审计（RB-010证据工作按需提前，不受编号限制）；任何存储结构变更都要保留旧档迁移；任何新视觉资产都要记录来源并通过实际查看。公开部署不在本 backlog 授权范围内。


固定全屏证据清单：菜单、故事、训练（选择工具/连接/测试/完成）、首次任务、施工、测试运行与暂停、失败、成功、提示/参考、Notebook空态/两案/历史、路线部分/全完成、沙盒及换载荷、最终结局、设置/存储失败/导入确认。每项记录目标桌面尺寸截图，关键施工/训练/结果/Notebook/路线另记录平板与319px压力组合；不能以一张菜单图代替。截图核对统一深绿面板、橙色支座/主行动、材料纹理、力量非纯颜色标记、字级间距与遮挡；另留输入/动态操作记录，静态图不证明可交互。缺少适用状态证据记Not tested，不能默认通过。


验证用离线候选可在 RB-014/RB-016 前生成，供独立验收实际解压运行；RB-017 是验收通过后封存最终候选，不是第一次生成包。修复后必须重建候选并重跑受影响的包验证，不得用旧包承接新代码的通过结论。
