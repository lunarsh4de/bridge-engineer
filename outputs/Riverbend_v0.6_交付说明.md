# Riverbend v0.6 完整离线游戏

本次按已确认开发模式完成 G0–G4：GPT-5.6-sol 实施，GPT-6.1 独立验收并反馈修复。没有公开发布。

## 玩游戏

解压 `riverbend-v0.6-offline-2026-11-06.zip`，双击根目录 `index.html`。已有解压目录 `Riverbend_v0.6` 可直接打开。不需要安装、服务器、账号、联网或 API Key；请保留旁边的 js、assets、vendor 文件夹。优先使用桌面 Chromium 浏览器。

- Start：四格故事与真实操作训练，可跳过；之后恢复主线。
- Select level：八关路线；Explore all levels 供教师抽查，不计为完成。
- Free build：独立沙盒和四档载荷，不影响主线。
- About：STEM 主题、学习目标、课程策略与模型范围。
- 通关后 Field report：个人设计缩略图、测量、社区后果、重玩与沙盒。

## 这一版完成了什么

保留从零搭桥与八关递进，补齐首入短任务、常驻目标、观察→原理两级提示、成功/失败不同主行动；把八个社区的配送前后变化落到场景和持久路线；整理 Notebook 的比较、最近记录、可选预测/反思及关卡证据问题；新增独立全屏工程回顾，并修正窄屏与低高度结果操作、启动失败解释与Retry、旧档迁移和部分完成报告。

STEM 不靠额外答题强行插入：玩家通过几何、连续载荷路径、材料拉压角色、中心桥墩和重载实验决定桥能否通过。可以无限重试，失败不会销毁原设计。不同设计可在相同条件下比较；材料奖励不按速度或失败次数扣分。教师资料在包内 teacher-docs。

## 迁移与继续修改

玩游戏只需离线ZIP。继续用Codex开发，可解压 `riverbend-v0.6-editable-project-2026-11-06.zip`，其中含可编辑HTML/CSS/JS、原始SVG美术、教学文档、计划、测试与打包脚本。先读 PROJECT_STATUS.md 与 README.md。开发测试需要Node与Playwright，运行游戏不需要。

保存进度换电脑前，进入 Help → Settings → Export progress；新电脑打开游戏后 Import progress 并确认。浏览器本地文件存储政策可能不同，请保留导出JSON。游戏离线包不包含任何模型、认证文件或凭据。
